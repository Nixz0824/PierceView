- ChatGPT/Codex 作为宿主时连续 20 次 F8 启用/恢复。

- 用户真实应用中的视觉质量；自动探针已确认 DWM 预览可建立，但不能替代肉眼检查黑帧、频闪和双圆。

这些项目涉及用户真实窗口、GPU、DPI 和桌面 Z-order，不能由纯逻辑测试替代。全部通过后才能把版本从 `1.0.0-rc.1` 改为 `1.0.0`。

## 已知限制

- 只识别 -1；-2、-3、-4 不属于 1.0。
- V6 以 3 px 条带近似圆边缘，仍可能看见轻微阶梯。
- 游戏、反作弊、DRM、无重定向和特殊 GPU 表面不保证视觉有效。
- 候选包未进行 Authenticode 签名；Defender 本机扫描无检出，但这不能替代代码签名信誉。
