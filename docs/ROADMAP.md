# 寸镜 / PierceView 产品路线图

路线已经冻结。新想法不得插入 1.0 候选版；每条路线独立开发、独立回归。

## 路线 1：PierceView 1.0 — V6 单层圆形稳定版

- 状态：当前路线，`1.0.0-rc.1` 用户验收中。
- 能力：按住 F8，圆内查看并点击紧贴宿主后的 -1 窗口。
- 产品形态：纯托盘小工具；设置只有半径和语言。
- 冻结项：不增加多层、深层识别、层级重排、矩形或羽化。

## 路线 2：PierceView 2.0 — 单层矩形 GPU 透视

- 先完成单层矩形硬边版本。
- 目标是减少圆形条带逼近带来的阶梯、频闪和双缓冲复杂度。
- 必须与 1.0 并行保留，不能直接覆盖稳定版。

## 路线 3：PierceView 2.1 — 矩形边缘羽化

- 在 2.0 稳定后加入 Alpha 渐变遮罩。
- “羽化”表示由当前层像素逐渐过渡到 -1 层，不是给边框加普通模糊。
- 验收重点是过渡连续、文字区域不出现明显重影、移动性能可接受。

## 路线 4：PierceView 2.5 — 最多四层与后台层级交换

- 最多识别 -1、-2、-3、-4；超过 -4 的窗口不识别、不显示、不参与点击重排。
- 支持在透视范围内同时表达多个层级。
- 点击深层窗口后，只在宿主后方重排，使被点击窗口成为新的 -1；宿主不能被越过。
- 该路线需要新的 GPU 合成和命中测试架构，不能继续堆叠在 V6 条带实现上。

## 版本纪律

- 1.0.x：只修稳定性、兼容性、文案和恢复问题。
- 2.0/2.1：只做单层矩形与羽化。
- 2.5：才允许加入最多四层与深层重排。
- 任一路线回归时，优先保留最近稳定版的安装包和 Git tag，确保可快速回退。
