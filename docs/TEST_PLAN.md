# 寸镜 / PierceView 1.0 测试计划

## 测试分层

| 层级 | 入口 | 覆盖内容 |
|---|---|---|
| Release 构建 | `dotnet build ... -c Release` | 编译、资源嵌入、0 警告 |
| 纯逻辑自检 | `dotnet PierceView.dll --self-test` | 参数、几何、设置规范化、JSON、中英文、测试开关 |
| 静态安全审计 | `tests/security-static-audit.ps1` | 禁止注入、内存访问、网络、合成输入、自启动、低级鼠标钩子 |
| 托盘冒烟 | `tests/tray-smoke-test.ps1` | 无主窗口、托盘生命周期、自动正常退出、无残留进程 |
| 单层窗口探针 | `PierceView.dll --probe-hwnd ...` | 圆心排除、连续移动耗时、旧圆心恢复、最终 region 恢复 |
| 非激活点击 | `tests/nonactivating-click-probe.ps1` | 来源收到真实点击、宿主前台不变、样式恢复 |
| 独立实机回归 | `tests/run-independent-single-layer-test.ps1` | 自动创建两个本地测试窗口并执行单层探针，避免依赖用户的 ChatGPT 窗口 |
| 用户视觉验收 | 手工清单 | 双圆、矩形叠加、黑帧、频闪、目标应用兼容性 |

`multilayer-visual-probe.ps1` 和 `constrained-zorder-promotion-probe.ps1` 是 2.5 预研遗留测试，不属于 1.0 发布门槛，不得用于宣称 1.0 支持多层。

## P0 自动化用例

1. Release 构建 0 警告、0 错误。
2. 版本输出与 `VERSION` 一致。
3. 设置半径被限制到 64–400，非法语言回退到中文。
4. 设置可原子保存、读取；损坏 JSON 安全回退默认值。
5. 源码不存在进程注入、网络、自启动和低级全局钩子。
6. 普通启动 700 ms 后进程仍运行且 `MainWindowHandle=0`。
7. 托盘测试自动退出后退出码为 0、没有残留 `PierceView` 进程。
8. 单层点击结束后宿主 region 和来源扩展样式与测试前一致。

## 用户验收清单

- [ ] 首次运行只有托盘提示，没有主窗口或控制台。
- [ ] 右键菜单仅有启动/暂停、设置、帮助、退出。
- [ ] 设置仅有半径和语言；中英文立即切换，保存后重启仍保留。
- [ ] 连续按住/松开 F8 20 次，无残留圆、矩形或被裁剪窗口。
- [ ] 按住 F8 移动 60 秒，始终只有一个圆；无持续频闪和明显双圆不同步。
- [ ] 圆内显示并可点击紧贴宿主后的单层应用，来源不会越过宿主到最前。
- [ ] 在两端都支持 Windows 原生拖放的测试应用间，从后台开始拖动，松开 F8 后可在宿主内完成放置；不支持的组合按兼容性说明处理。
- [ ] 暂停后 F8 无效果，重新启动后恢复。
- [ ] 退出后托盘图标和进程消失，目标窗口完整恢复。
- [ ] 帮助明确单层限制和游戏退出要求。

## 兼容性矩阵

候选版至少记录以下组合：Windows 10/11、100%/150%/200% DPI、单屏/双屏、Intel/AMD/NVIDIA 中实际可获得的 GPU；应用至少覆盖记事本、文件资源管理器、普通浏览器页面、ChatGPT/Codex 类 Electron/Chromium 窗口。

游戏、反作弊、DRM 和 UAC 安全桌面不执行绕过性测试，只验证文案和退出策略。

## 通过标准

自动化全绿只能证明基础工程和恢复路径可用。`1.0.0` 还必须由用户完成真实桌面视觉验收；若出现持续黑帧、双圆、矩形叠加或恢复失败，保持 RC 状态并回退修复，不以文档替代缺陷处理。
