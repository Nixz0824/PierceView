# 寸镜 / PierceView 1.0 产品需求文档（PRD）

- 文档版本：1.0
- 对应产品：1.0.0-rc.1
- 状态：用户验收候选版
- 产品形态：Windows 系统托盘小工具

## 1. 产品定义

寸镜（PierceView）让用户在不切换当前工作窗口的情况下，按住 `F8` 临时查看并操作其后紧贴的一层普通桌面应用。它启动后只驻留系统托盘，不提供常驻主窗口、前端站点、后端服务或账号系统。

## 2. 问题与初衷

多应用、多网页工作时，很多次 `Alt+Tab` 只是为了确认后台的一小段文字、一个状态或几项数据。完整切换一次再切回来，会打断当前输入、阅读和思考。寸镜把这种“只看一眼”的动作压缩成按住 F8：看完、滚动或点完就松开。

它也允许更灵活的工作方式。在兼容 Windows 原生拖放的应用之间，用户可以从后台开始拖动文字、图片或文件，松开 F8 让当前应用重新完整显示，再在目标位置放手。等待 AI 处理或回复时，用户也可留在当前上下文里临时查看后台资讯或短暂休息。

## 3. 1.0 目标

1. 恢复并固化 V6 的单层圆形透视体验。
2. 保证只出现一个圆，移动稳定，松键和退出后恢复宿主窗口。
3. 允许圆内真实鼠标操作下一层应用，同时尽量保持宿主窗口在最前。
4. 用最少的托盘菜单、设置、帮助和中英文文案形成可独立使用的候选版。
5. 明确兼容性和游戏安全边界，不承诺支持所有 GPU/受保护窗口。

## 4. 非目标

- 1.0 不同时显示多个后台层级。
- 1.0 不识别、点击或提升 -2、-3、-4 窗口。
- 不提供矩形透视、羽化边缘、自定义快捷键、主题、账户、云同步、自动更新或规则中心。
- 不绕过 DRM、反作弊、UAC 安全桌面或 Windows 权限隔离。
- 不做商业化平台、前后端架构或安装服务。

## 5. 核心体验

1. 用户启动 `PierceView.exe`，程序只进入系统托盘。
2. 首次运行显示一次简短提示：“把鼠标移到目标应用上，按住 F8 开始透视。”
3. 用户按住 `F8`，寸镜锁定鼠标下的宿主顶层窗口并打开圆形透视。
4. 用户移动鼠标，物理缺口和视觉预览使用同一次坐标更新。
5. 用户可在圆内滚动、点击后方单层应用；寸镜阻止该来源窗口越过宿主。
6. 支持原生拖放的应用可以从后台开始拖动，松开 F8 后在当前应用内完成放置。
7. 用户松开 `F8`、暂停透视或退出，窗口 region 与临时扩展样式立即恢复。

## 6. 功能需求

| ID | 需求 | 验收标准 |
|---|---|---|
| FR-001 | 纯托盘运行 | 普通启动后 `MainWindowHandle=0`，任务栏没有常驻主窗口 |
| FR-002 | F8 单层圆形透视 | 按住启用、移动跟随、松开恢复；同一时刻只出现一个圆 |
| FR-003 | 单层视觉来源固定 | 每次 F8 会话只使用首次命中的 -1 来源，不扫描或切换深层窗口 |
| FR-004 | 非激活鼠标交互 | 来源窗口收到真实点击和滚动；宿主保持前台，结束后来源样式恢复 |
| FR-004A | 兼容应用跨窗口拖放 | 支持原生拖放的测试应用可从后台开始拖动，松开 F8 后在宿主目标处完成放置；不兼容时有边界说明 |
| FR-005 | 托盘菜单 | 仅包含启动/暂停、设置、帮助、退出 |
| FR-006 | 最小设置 | 仅包含半径 64–400 和简体中文/English；保存后立即生效 |
| FR-007 | 帮助与首次提示 | 说明 F8、单层限制、游戏退出要求；首次提示不形成向导 |
| FR-008 | 单实例 | 再次启动不创建第二个后台实例，并提示从托盘操作 |
| FR-009 | 恢复 | 松键、暂停、托盘退出、正常进程退出路径恢复窗口状态 |
| FR-010 | 品牌 | 托盘和设置窗口使用已确认的 v5 黑白 Logo，不在 Logo 图形内加文字 |

## 7. 非功能需求

- 性能：默认 16 ms 轮询；鼠标静止时跳过重复 DWM 更新。
- 稳定性：Release 构建必须 0 警告；自动测试不得残留 PierceView 进程。
- 安全：`asInvoker`、`uiAccess=false`；无注入、驱动、进程内存访问、合成输入、网络和全局低级鼠标钩子。
- 隐私：只在本机保存半径和语言，不采集遥测。
- 可访问性：设置项使用系统字体、明确标签、键盘默认按钮和取消按钮。

## 8. 发布判定

`1.0.0-rc.1` 只有在自动测试通过且用户对真实应用完成以下验收后，才能改为 `1.0.0`：

- 连续 20 次按住/松开 F8 无残留矩形、双圆或视觉失效。
- 持续移动 60 秒无不可接受的频闪、黑帧或圆心明显不同步。
- 在 ChatGPT/浏览器/文件管理器等目标组合中，单层画面和点击符合说明。
- 暂停、恢复、设置半径、切换语言、退出均正常。

未来功能不进入 1.0 补丁版本，统一按[路线图](ROADMAP.md)另行开发。
