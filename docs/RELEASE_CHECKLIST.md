# 寸镜 / PierceView 发布检查清单

## 每个候选版

- [ ] `VERSION`、csproj、CHANGELOG、测试报告一致。
- [ ] Release 构建 0 警告、0 错误。
- [ ] 纯逻辑自检、静态安全审计、托盘冒烟测试通过。
- [ ] 单层窗口探针和非激活点击测试通过。
- [ ] 托盘菜单只有启动/暂停、设置、帮助、退出。
- [ ] 设置只有半径和语言；首次提示和中英文帮助正确。
- [ ] v5 Logo 已嵌入托盘与设置窗口。
- [ ] 最终发布物重跑适用测试并记录 SHA256、文件大小和构建时间。
- [ ] 更新兼容性、已知问题和用户验收清单。
- [ ] 不提交包含私人桌面内容的截图或日志。

## 从 RC 升为 1.0.0

- [ ] 用户完成 20 次启用/恢复和 60 秒移动测试。
- [ ] ChatGPT/浏览器/文件资源管理器组合中单层视觉与点击通过。
- [ ] 未观察到持续矩形叠加、双圆、黑帧或恢复失败。
- [ ] 暂停、重新启动、设置保存、语言切换和退出通过。
- [ ] Defender 扫描最终 EXE，记录引擎/病毒库版本与结果。
- [ ] 明确未签名 SmartScreen 风险；若公开分发，优先完成 Authenticode 签名。
- [ ] 保留上一个稳定包和 Git tag，验证可回退。

## 不属于 1.0 的项目

- 多层合成、深层窗口提升和最多四层识别。
- 矩形 GPU 透视和 Alpha 羽化。
- 安装器、自动更新、账号、云服务、规则中心。

这些能力按 `docs/ROADMAP.md` 独立立项，不能作为 1.0 发布阻塞项，也不能临时塞回 1.0。
