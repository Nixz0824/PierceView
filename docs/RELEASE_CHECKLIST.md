# WindowPortal 发布检查清单

## 每个版本

- [ ] `VERSION`、csproj Version、CHANGELOG 一致。
- [ ] Release 构建 0 警告、0 错误。
- [ ] 纯逻辑自检通过。
- [ ] 静态安全审计通过。
- [ ] 单层点击、深层提升、三层视觉与运动测试通过。
- [ ] 最终单文件发布物重跑所有适用测试。
- [ ] 生成 SHA256。
- [ ] 更新兼容性矩阵和已知问题。
- [ ] 保存测试日志与截图，但不提交包含私人桌面内容的诊断文件。

## 0.9/1.0 额外门槛

- [ ] SBOM 与依赖漏洞扫描。
- [ ] Windows Defender 与至少一个独立多引擎服务扫描；记录日期和规则版本。
- [ ] 安装/卸载、自动更新、回滚验证。
- [ ] watchdog 强制终止恢复验证。
- [ ] Windows/DPI/GPU 矩阵完成。
- [ ] 隐私、安全、支持与漏洞报告流程发布。
